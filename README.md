# LA MOVIDA · Manual de marca interactivo

Versión web del manual de marca de **LA MOVIDA**, la identidad de UNICEF para el Día Mundial de la Infancia 2026. *La infancia nos mueve.*

Sitio estático (HTML + CSS + JS, animaciones con [GSAP](https://gsap.com/)). No requiere compilación.

## Contenido
Concepto · Planimetría · Área de protección · Paleta de color · Colores secundarios · Tipografía · Iconografía · Versiones · Usos correctos · Usos incorrectos · Descargas

## Activos
Los trazos del logotipo, el isotipo, la firma institucional y los 12 íconos se extrajeron como vectores directamente del PDF original del manual (`assets/manual-de-marca-la-movida.pdf`); no fueron redibujados.

- `assets/logo-*.svg`, `assets/isotipo.svg`: versiones del logotipo
- `assets/icons/*.svg`: sistema de íconos (96 × 96 px, trazo 7 px)
- `assets/kit-la-movida.zip`: kit completo de descarga
- `assets/brand.js`: datos vectoriales usados por el sitio

## Ver localmente
Abrir `index.html` en el navegador.
